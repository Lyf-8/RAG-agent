# 智能办公系统用户手册

## 1. 系统概述

智能办公系统（SmartOffice）是一套面向中大型企业的综合性办公管理平台，涵盖考勤管理、审批流程、文档协作、数据分析等核心功能模块。系统支持Web端和移动端双平台访问，满足企业日常办公全场景需求。

### 1.1 适用对象

本手册适用于以下人员：
- 企业系统管理员：负责系统配置、用户管理和权限分配
- 部门管理者：负责审批流程配置和团队管理
- 普通员工：使用考勤打卡、提交审批、协作文档等日常功能

### 1.2 系统版本

当前版本：SmartOffice v3.2.1
发布日期：2025年9月15日
支持平台：Windows 10+、macOS 12+、Android 10+、iOS 14+

## 2. 考勤管理模块

### 2.1 打卡方式

系统支持三种打卡方式：

1. GPS定位打卡：员工到达办公区域后，打开移动端App，系统自动获取GPS定位，在有效范围内即可完成打卡。定位精度为50米，若定位失败可手动重试。

2. WiFi打卡：连接公司指定WiFi后，系统自动识别并完成打卡。适用于室内GPS信号弱的场景。WiFi名称需与管理员预先配置的SSID一致。

3. 蓝牙打卡：通过公司部署的蓝牙信标设备，员工靠近信标2米范围内即可自动打卡。此方式需要在手机上开启蓝牙功能并授权App访问。

### 2.2 请假审批流程

请假审批遵循以下流程：

员工提交请假申请 → 直属主管审批（24小时内） → HR备案 → 考勤系统自动扣减年假
- 请假1天以内：直属主管审批即可生效
- 请假1-3天：直属主管审批 + 部门经理审批
- 请假3天以上：直属主管审批 + 部门经理审批 + 分管副总审批

### 2.3 加班管理

加班需提前在系统中提交申请，经主管审批通过后方可认定为有效加班。加班补偿方式有两种：
- 调休：按1:1比例折算调休时长，有效期90天
- 加班费：工作日按1.5倍计算，周末按2倍计算，法定节假日按3倍计算

## 3. 审批流程模块

### 3.1 审批类型

系统内置以下审批类型，企业也可自定义扩展：
- 通用审批：适用于日常事务性申请
- 采购审批：涉及金额审批，需按金额分级审批
- 合同审批：需法务部门审核合同条款
- 报销审批：需财务部门核实票据

### 3.2 采购审批规则

采购金额对应审批层级如下：
- 1000元以下：直属主管审批
- 1000-5000元：直属主管 + 部门经理审批
- 5000-20000元：直属主管 + 部门经理 + 财务总监审批
- 20000元以上：直属主管 + 部门经理 + 财务总监 + 总经理审批

所有采购需附正规发票，电子发票需上传PDF原件，纸质发票需扫描上传。发票抬头必须与企业名称一致，税号需准确无误。

### 3.3 审批时效要求

各类审批的时效要求：
- 通用审批：24小时内处理
- 采购审批：48小时内处理
- 合同审批：3个工作日内处理
- 报销审批：5个工作日内处理

超过时效未处理的审批，系统将自动催办，连续3次催办未处理将上报至上级管理者。

## 4. 文档协作模块

### 4.1 文档权限

文档权限分为四个等级：
1. 所有者：可编辑、分享、删除、设置权限
2. 编辑者：可编辑内容，不可删除和分享
3. 评论者：可查看和评论，不可编辑内容
4. 查看者：仅可查看，不可编辑和评论

### 4.2 版本管理

系统自动保存文档编辑历史，每次保存生成一个版本快照。用户可查看任意历史版本，并支持版本回滚。版本保留策略如下：
- 最近30天的版本：全部保留
- 30-90天的版本：每天保留最后一个版本
- 90天以上的版本：每周保留最后一个版本

## 5. 数据分析模块

### 5.1 数据报表

系统提供以下标准报表：
- 考勤月报：统计部门/个人月度出勤率、迟到次数、请假天数
- 审批效率报表：统计各类审批的平均处理时长、超时率
- 文档活跃度报表：统计文档的编辑频次、协作者数量

### 5.2 自定义看板

管理员可创建自定义数据看板，从多个数据源选择指标，配置图表类型（柱状图、折线图、饼图），设置刷新频率。看板支持导出为PDF或Excel格式，可定时发送至指定邮箱。

## 6. 系统管理

### 6.1 用户管理

系统管理员可添加、停用、删除用户账号。新用户首次登录需修改初始密码，密码复杂度要求：8位以上，包含大小写字母和数字。连续5次密码错误将锁定账号30分钟。

### 6.2 权限配置

权限配置基于角色（RBAC模型），系统预设以下角色：
- 超级管理员：拥有所有模块的全部权限
- 系统管理员：可管理用户和基础配置，不可查看财务数据
- 部门管理者：可管理本部门成员和审批流程
- 普通员工：基础办公权限

自定义角色可由超级管理员创建，从权限清单中勾选具体权限项，实现精细化权限控制。

### 6.3 系统日志

系统记录所有关键操作日志，包括登录日志、审批操作日志、文档操作日志、权限变更日志。日志默认保留180天，管理员可配置保留时长。日志支持按时间、操作人、操作类型筛选查询，可导出为CSV格式。

## 7. 常见问题

### 7.1 打卡失败怎么办？

若GPS打卡失败，请依次尝试：1）检查手机定位服务是否开启；2）切换WiFi打卡方式；3）联系管理员检查办公区域围栏配置。若仍无法解决，可提交人工补卡申请，由主管审批后生效。

### 7.2 忘记密码怎么办？

点击登录页"忘记密码"链接，输入注册邮箱，系统发送重置链接至邮箱（链接有效期30分钟）。若邮箱也无法访问，请联系系统管理员重置密码。

### 7.3 审批被驳回后能否重新提交？

可以。被驳回的审批可在"我的审批-已驳回"列表中找到，点击"重新提交"按钮，修改内容后重新提交。重新提交的审批将重新走完整审批流程。
